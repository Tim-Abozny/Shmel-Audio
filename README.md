# 🎛 ShmelAudio

A modern Windows desktop tool for visualizing and managing application audio levels in real time.  
Includes per-app volume control, decibel limits, dark UI, tray minimization, and smooth visualizer bars.

---

## 📥 How to Install

1. Download the installer:  
   👉 **[ShmelAudio_Installer.exe](https://github.com/Tim-Abozny/Shmel-Audio/releases/download/ShmelAudio/ShmelAudio_Installer.exe)**

2. ⚠ **Make sure you have .NET Desktop Runtime installed**:  
   - Download: https://dotnet.microsoft.com/en-us/download/dotnet
   - Link for .NET 8: https://dotnet.microsoft.com/en-us/download/dotnet/8.0
   - Required: **.NET Desktop Runtime 8.0 or later**

3. Run `ShmelAudio_Installer.exe` and follow the steps.

---

## ✨ Features

- 🔊 Per-application volume control  
- 🔒 Max volume limiter for each app (in % or dB)  
- 📈 Real-time audio visualizer with smooth bars, peaks, and reflections  
- 🌙 Modern dark UI with rounded edges  
- 🎛 Tray icon support with open/exit menu  
- 💾 Automatic preset saving  
- 🔄 App auto-start on boot
